## Configuración

* Instala Node v20.12.2. Puedes utilizar un gestor de versiones como [nvm](https://github.com/nvm-sh/nvm) para instalar y gestionar versiones de Node.js.

```bash
# Instala nvm si aún no lo tienes
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh | bash

# Instala Node.js v20.12.2
nvm install 20.12.2

# Utiliza Node.js v20.12.2
nvm use 20.12.2
```

* Asegúrate de instalar las dependencias:
```bash
# npm
npm install
```

## Servidor de desarrollo

Arranca el servidor de desarrollo en `http://localhost:3000`:

```bash
# npm
npm run dev
```

## Producción

Construye la aplicación para producción:

```bash
# npm
npm run build
```

Previsualiza localmente el build de producción:

```bash
# npm
npm run preview
```

Consulta la [documentación de despliegue](https://nuxt.com/docs/getting-started/deployment) para más información.
