# Documentació de Nuxt 3

## Configuració

* Instal·la Node v20.12.2. Pots utilitzar un gestor de versions com [nvm](https://github.com/nvm-sh/nvm) per instal·lar i gestionar versions de Node.js.

```bash
# Instal·la nvm si encara no el tens
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.3/install.sh | bash

# Instal·la Node.js v20.12.2
nvm install 20.12.2

# Utilitza Node.js v20.12.2
nvm use 20.12.2
```

* Assegura't d'instal·lar les dependències:
```bash
# npm
npm install
```

## Servidor de desenvolupament

Arrenca el servidor de desenvolupament a `http://localhost:3000`:

```bash
# npm
npm run dev
```

## Producció

Construeix l'aplicació per a producció:

```bash
# npm
npm run build
```

Previsualitza localment el build de producció:

```bash
# npm
npm run preview
```

Consulta la [documentació de desplegament](https://nuxt.com/docs/getting-started/deployment) per a més informació.
