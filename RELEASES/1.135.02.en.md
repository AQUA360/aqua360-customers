# Product release 1.135.02 — 16-10-2026

| Component | Version |
|---|---|

| Frontend | 1.123.00 |

Product PATCH bump with an urgent backend fix (500 on `/ov/contract-detail/`). The product number jumps from `1.135.01` to `1.135.02` because the `v1.135.01` tag was already taken (previous product release, Docker only).

## Highlights

- Fixed the `500` (`NoReverseMatch`) on `GET /ov/contract-detail/?contract_token=<token>` when the token contains a slash (`/`): the view now responds directly with `200` and the contract detail instead of redirecting to `/ov/contract/{token}/`, which cannot resolve a `<str:token>` with a slash.
