## Highlights

- SII export: new invoice type classification, and non-subject bases declared as `NoSujeta`.

## Changes

### Backend

- FIX: SII export: invoices of €200 or more (previously €400) or for legal-entity customers are declared as `F1` (or `R1` if corrective); the rest as `F2` (or `R5`) (#270).
- FIX: SII export: the untaxed base is declared under `NoSujeta` (`ImportePorArticulos7_14_Otros`) instead of `Sujeta/Exenta` with cause `E1`, and `Sujeta/NoExenta` with the VAT breakdown is only included when there are taxed bases (#270).

### Frontend

- No changes.

## Notes

- No migrations, opscripts, environment variables or new ConfigProject entries.
- SII files generated from this version on may differ in invoice type and structure from those generated with `v1.152.00`.
- **Images:** with `CUSTOMERS_VERSION=v1.152.01` in `.env`, `docker compose pull && docker compose up -d`.
