## Highlights

- Automatic submission of daily documents to the SII, with the status of each submission and error alerts.
- Unpaid fees on overdue invoices, as a bulk operation running in the background.
- Billing period chosen when creating a billing run, and billing processing errors that are clear and can be reprocessed.
- Contract invoices by year and by the biller's period, with payment status and returns in the invoice lists.
- SEPA returns for an invalid account: the direct debit is removed and the contract moves to bank payment.
- Per-user customizable sidebar menu, with favourites, and a settings page with tabs and search.
- Master tables for meter manufacturers, models and communication technologies, and a warning when assigning a meter that is already at another supply point.
- Lecturapp: reading photo gallery, and the property's clusters with their photos.
- Client plugins loaded outside the public image, and the real deployment version and date in the menu.

## Notes

- **Deploy backend and frontend together.** Many PRs touch both sides (#266, #281, #282, #286, #314, #316, #324, #331, #333…).
- **No new dependencies.**
- **Migrations** (`migrate`):
  - billing `0339`–`0345` (`0342` merges the two `0341`)
  - communication `0040`
  - contract `0250`
  - coredata `0155`–`0157`
  - dashboard `0002`
  - pricing `0139`
  - service `0145`
  - statistics `0052`, `0054`, `0055` and `0057` (`0053` and `0057` are merge migrations)
  - There are data migrations:
    - `coredata.0155` moves `uses_aca` to `public_org_type` (`aca` or empty) and enables or disables the `aca_summary_report` and `factdeta_report` reports based on that value (#273).
    - `billing.0339`, `0341`, `0344` and `coredata.0156` create ConfigProject entries (see below).
- **Opscripts** (`manage.py run_pending_scripts`):
  - `service/0002`: «Photos» cluster document type (only if it does not exist) (#320).
  - `statistics/0005_load_daily_document_submission_statuses`: submission statuses for daily documents (#316). It shares its number with `0005_add_wallet_debt_balance_at_date_report`, but the runner records them by name and both run.
- **New ConfigProject entries:**
  - `public_org_type` (replaces `uses_aca`): `aca` enables the «ACA bonuses» menu, the ACA settings and reports; empty hides them (#273).
  - `unpaid_fee_operation_enabled` (default `false`): shows the unpaid fees operation (#282).
  - `sepa_invalid_account_reject_tokens` (default `AC01,AC04,AC06,AC13,AG01,BE06,MD07,RC01`): **enabled by default**; empty disables the switch to bank payment on invalid-account returns (#300).
  - `block_remittance_if_unpaid` (default `false`): new invoices of contracts with debt move to bank payment (#322).
  - `budget_due_date_days` (default `60`): due days for budgets (#304).
  - `invoice_chart_bar_color` (default empty): bar colour of the invoice chart (#317).
- **New environment variables:**
  - `SII_ENABLED` (default `False`), `SII_ENVIRONMENT` (`test` or `prod`), `SII_USE_SEAL_CERT` (`True`), `SII_TIMEOUT` (60 s) and `SII_VERIFY_SSL` (`True`): automatic SII submission (#316).
  - `PLUGINS` and `PLUGIN_IMAGE_<name>`: client plugins. Without `PLUGINS` nothing changes. `BACKEND_IMAGE` is not used (#280, #334).
  - Build args `APP_VERSION`, `GIT_COMMIT`, `GIT_COMMIT_DATE`, `GIT_BRANCH` and `BUILD_DATE`: GitHub images already include them; they are optional in a local build (#291).
- **New management commands:**
  - `fix_order_change_meter_readings`: repairs the consumption of readings from meter changes made by work orders (without `--apply` it only reports; `--contract` limits it to one contract) (#318). **Run it after deploying**, first without `--apply`; readings already invoiced are reported with a warning and their invoice must be reviewed by hand.
  - `populate_meter_dictionaries`: fills the meter master tables with the values the meters already have (idempotent, with `--dry-run`) (#281). **Run it once after deploying.**
  - `record_deploy`: records the deployed version; the backend entrypoint already calls it on startup (#331).
- **Behaviour changes:**
  - #300: with the default setting, a SEPA return with one of the invalid-account reasons deactivates the holder's account and moves the contract and its pending invoices to bank payment.
  - #298: remittances marked as sent can no longer be modified, deleted, regenerated or sent again.
  - #328: claims are finished or cancelled automatically depending on the payment status.
  - #273: installations outside Catalonia (without `uses_aca`) no longer see the ACA menu, settings and reports.
  - #281: the meter manufacturer, model and technology dropdowns no longer accept typing a new value; new values are created with the «+» button or in the master tables.
  - #332: the meter change API returns 409 (`meter_assigned`) if the meter is at another supply point and `confirm_reassign` is not sent.
  - #309: `POST /ov/procedures/contract/` and `contract-change/` create the holder if the DNI does not exist (previously 404); name, surname, phone and email must be sent.
  - #321: Virtual Office consumption no longer shows readings of previous holders of the same supply point.
  - #329: new Lecturapp endpoints for clusters and their photos; they go with the new app version.
  - #318: new meter change readings have the «Meter change» origin; old ones keep `order_change_meter` until the repair command is run.
- **Images:** with `CUSTOMERS_VERSION=v1.157.00` in `.env`, `docker compose pull && docker compose up -d`, then `docker compose exec backend python manage.py migrate --noinput` and `docker compose exec backend python manage.py run_pending_scripts`. Then `populate_meter_dictionaries` and `fix_order_change_meter_readings` (see above).
