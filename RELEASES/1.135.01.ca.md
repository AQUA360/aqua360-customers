## Highlights

- Imatges del backend i del frontend construïdes a GitHub en publicar una release i publicades a `ghcr.io/aqua360/aqua360-customers-backend` i `-frontend`, amb l'etiqueta de la release i la del commit. Els servidors les baixen en lloc de construir-les.
- `docker-compose.yml`: la versió de les imatges es tria amb `CUSTOMERS_VERSION` al `.env`. Sense, es construeix al servidor com fins ara, amb una imatge per stack (`local-<stack>`).
- `gmao-consumer` opcional per client amb el perfil `gmao` (`COMPOSE_PROFILES=gmao`), i prova de salut sense `ps`.
