## Highlights

- Customer service (SAC) incident management: assignment, channels, deadlines with holidays, warnings and escalations, timeline and compliance report.
- New call register with start and end times, customer-initiated calls and email contacts, linked to incidents.
- "Requested downloads" screen to download invoices and communication process documents as a PDF or in batches.
- Dedicated price rates and work orders for change-of-name requests.
- Smart Metering: loads by routes, zones or batches, and Smart Metering reading when editing readings.
- Unpaid debt management: invoices from registration requests and pending terminations, contract export and attachments per template.
- Security: critical fixes for users, GOT documents, global search and the document manager.

## Notes

- **Deploy backend and frontend together.** Almost every PR touches both sides.
- **Migrations** (`migrate`):
  - billing `0327`–`0332`
  - communication `0036`–`0037`
  - contract `0245`, `0246` and `0248` (`0247` belongs to PR #159, which is not in this release)
  - coredata `0145`–`0151` (some numbers are repeated, resolved with merge migrations)
  - logger `0055`
  - notification `0026`–`0027`
  - service `0136`–`0138`
  - statistics `0049`–`0050`
  - There are data migrations:
    - `communication.0036` moves the `ATTACH_CLAIM_DOCUMENTS_ENABLED` ConfigProject to every template and deletes it.
    - `contract.0246` and `contract.0248` copy the current price rates and order types into the change-of-name lists.
    - `service.0137` merges repeated values in the meter dictionaries before `0138` adds uniqueness constraints.
    - `notification.0027` creates the default input channels and fills in the closing date of closed incidents.
    - `coredata.0145`, `coredata.0148` and `statistics.0050` create ConfigProject entries and the new compliance report.
  - `billing.0327` adds back the `start_date` column of `CommitmentDeposit` and `PaymentCommitment`, which `billing.0324` had dropped. Previous values are not recovered.
- **Opscripts** (`manage.py run_pending_scripts`):
  - `contract/0005`: marks the termination type in `termination_type_holder_change` and its linked requests as change of name. It does not reassign price rates or orders.
  - `coredata/0005`: recalculates the search text of addresses that have an extension.
- **New ConfigProject entries:**
  - `contract_housing_units_variable_type_token` (#140, default `general`).
  - `contract_min_persons` (#160, default `3`).
  - `use_exploitation_token_for_payment` (#163, default `false`). Only works with numeric exploitation tokens below 10.
  - `incident_retention_years` (#148, default `5`) and `incident_channel_app_token` (#148, default `app`).
  - `attach_invoices_in_claims` (#149, default `true`; created on first use).
  - `ATTACH_CLAIM_DOCUMENTS_ENABLED` is removed: it is now set on each template (#145).
- **Celery:**
  - The `beat_schedule` changes (#148): `check-due-incidents` (daily at 00:27) and `check-incident-deadlines` (every 15 minutes). Restart beat and the workers.
  - The "Requested downloads" screen (#155) needs the worker running.
- **New management commands:**
  - `manage.py incident_retention [--purge]` lists, and with `--purge` deletes, soft-deleted incidents past the retention period (#148).
  - `manage.py repair_claim_payment_contracts` fills in the contract of unpaid debt management payments that have none (#143).
- **Behaviour changes:**
  - #139: `/got/orders/view-document/<id>/` requires the `X-App-Token` header. Global search requires authentication.
  - #139: users who manage users without being superusers need the `change_user` permission. Deleting groups or editing superusers requires being a superuser.
  - #139: the document manager only serves and deletes files inside `DOCUMENT_MANAGER_PATH`, which must match the real document path (currently `/app/media/documents/`).
  - #166: rebilling uses the original invoice parameters (people and price rates) by default, not the current contract ones.
  - #162: a request is a change of name only if it is created from the contract's "Change of name" action.
  - #161: the communications email field accepts several addresses separated by `;`, not commas.
- **Environment variables:** none new for deployments. `TEST_SCHEMA_FILE` (#170) is only used by CI.
- **Images:** with `CUSTOMERS_VERSION=v1.145.00` in `.env`, `docker compose pull && docker compose up -d`, then `docker compose exec backend python manage.py migrate --noinput` and `docker compose exec backend python manage.py run_pending_scripts`.
